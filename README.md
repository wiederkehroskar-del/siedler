# Siedler 3D

Download-Seite für Siedler 3D, ein Aufbauspiel nach dem Vorbild von Die Siedler III, gebaut mit Unreal Engine 5.8.
Fan-Projekt, nicht mit Ubisoft oder Blue Byte verbunden.

Die Seite liegt in `index.html` und wird über GitHub Pages ausgeliefert. Die Spieldateien hängen unter **Releases**.

## Neue Version eintragen

In `seite.html` im `<script>`-Teil steht die Liste `VERSIONEN`. Einen neuen Block oben anfügen,
`url` auf die Release-Datei zeigen lassen, dann `./mache-index.sh` ausführen.
